# Spatial Pointer v0.1

スマホそのものの位置と向きで、Blender内の3Dポインタを動かす構想の「Blender側・最初の実験」です。
2Dマウスカーソルやタッチパッドの置き換えではありません。画面の奥行きを持つポインタを動かし、選択した物体を掴んで移動・回転させます。

**この版にはiPhoneアプリ・IPA・スマホの位置計測・スカルプト変形は含まれません。**
Blender内のキーボード模擬入力と、将来のスマホ入力を受け取るUDP受信口を実装しています。

## 対象と検証の区別

- 対象バージョン：Blender 4.2以降のExtension形式。これはマニフェストの対応下限であり、全バージョンでの実機検証済みという意味ではありません。
- アドオンはBlender同梱のPythonだけで動く設計です。PC操作モードに外部Pythonのインストールは不要です。
- 内部ロジック、UDPループバック、構文、ZIP構造を自動テストしています。
- 作成環境にBlender実行環境がなく、Blender本体でのインストール・UI・操作感の確認は未実施です。詳細と自己テストは開発キットのVERIFICATION.md、tests/blender_smoke.pyを参照してください。

## インストール

1. `spatial_pointer-0.1.1.zip`をPCに保存します。**このZIPは解凍しません。**
2. Blenderを開き、`Edit（編集）→ Preferences（プリファレンス）→ Add-ons（アドオン）`を開きます。
3. 右上のメニューから`Install from Disk（ディスクからインストール）`を選び、ZIPを指定します。表示場所はBlenderの版・翻訳によって多少異なります。
4. `Spatial Pointer`を有効にします。
5. 3Dビューポート上にマウスを置いて`N`キーを押し、右サイドバーの`Spatial`タブを開きます。

開発キット全体のZIPは直接インストールできません。キットを解凍した場合は`Install/spatial_pointer-0.1.1.zip`を指定します。

## 最初に試す順番

1. 重要な作業は保存してから、`Open Practice Scene`を押します。専用の`Spatial Pointer Lab`シーンを追加します。元のシーン・オブジェクトは削除しません。2回目以降は同じ練習シーンを開きます。
2. `Start Keyboard Test`を押します。
3. `D`で右へ、`E`で上へ、`W`で奥へポインタを動かします。これはBlenderのワールド座標基準です。視点の向きによって、画面上の移動方向は変わります。
4. `F`でポインタを選択中のキューブの原点へ戻します。
5. **Spaceを押し続けたまま**`W/A/S/D/Q/E`でキューブを動かします。Spaceを離すと、その場所に置きます。
6. Spaceを押し続けて`J/L`などを押すと、掴んだ物体をポインタの周りに回転できます。
7. `Enter`でテストを終了します。`Esc`では進行中の掴み操作だけを取り消して終了します。すでに離した物体まで全部初期化する操作ではありません。

通常のマウス選択・中ボタンによる視点回転・ホイールは使用可能にする設計です。通常のBlenderキー操作へ完全に戻すときは、先にEnterでテストを終了してください。

## キー一覧

| キー | 機能 |
|---|---|
| A / D | -X / +X：左右移動 |
| W / S | +Y / -Y：前後移動 |
| Q / E | -Z / +Z：上下移動 |
| I / K | ポインタのローカルX軸周りに回転 |
| J / L | ポインタのローカルZ軸周りに回転 |
| U / O | ポインタのローカルY軸周りに回転 |
| Spaceを保持 | 選択中のアクティブオブジェクトを掴む |
| Spaceを離す | 物体を置く |
| Shiftを保持 | 移動・回転速度を15%にして精密操作 |
| C | FollowのON/OFF。OFF中に入力を動かしてもポインタは固定 |
| R | ポインタを動かさず、入力の基準だけを取り直す |
| F | ポインタを選択物体の原点へ移す |
| Enter | 現在位置を保って入力を停止 |
| Esc | 現在掴んでいる物体を掴み開始前に戻し、入力を停止 |

### クラッチを確認する実験

Dを押して少し移動 → Cで追従OFF → Dを押して模擬入力だけを大きく移動 → Cで追従ON。
再開時にポインタが飛ばず、その後の移動分から追従すれば狙いどおりです。指を画面から離す動作に相当するON/OFFを、今回はCキーで代用しています。

## パネルの意味

- **Follow input**：チェックを外すと追従停止。持ち直し後の再開で基準を取り直します。
- **Grab Selected / Release / Cancel Grab**：マウスでボタンを押しても掴む・離す・掴み取消ができます。
- **Pointer to Selection**：ポインタだけを選択物体の原点に移動します。
- **Restore Last Grab**：直近に離した物体を、その掴みの開始前に戻します。最大20件。ファイル読み込み、グローバルUndo/Redo、レンダー開始、アドオン無効化で履歴を破棄します。
- **Motion gain**：入力の移動量に掛ける倍率。ARKit入力では「現実の1mに対するBlender単位」です。
- **Smooth half-life**：小さいほど追従が速くなります。0で平滑化なし。初期値0.035秒はフィルタ設定であり、実測の通信遅延ではありません。
- **Also move Blender 3D Cursor**：ONにした場合だけ、Blender標準の3Dカーソルにも反映します。標準3Dカーソルとこのポインタは別物です。

## できないこと・安全上の注意

- スマホを空中で動かす実機体験は、このZIPだけではできません。スマホ側の6DoF計測・送信アプリを次段階で追加する必要があります。
- ポインタをモデル表面に近づけると自動選択される機能はありません。先に通常のマウスで対象を選択します。
- スカルプト、頂点の押し引き、筆圧、表面への吸着、専用SpaceMouseドライバ互換は未実装です。
- Object Mode専用です。拘束の有効なオブジェクト・ロックされた変形・読み取り専用リンクオブジェクトは対象外です。アニメーション・リグ・非一様スケールの親を持つ物体も最初の試験対象にはしないでください。
- 通常のCtrl+Zではなく、まず`Cancel Grab`または`Restore Last Grab`でこのアドオン内の操作を戻してください。
- アドオン無効化で練習シーンを勝手に削除しません。補助オブジェクトだけを消すにはTuning内の`Remove Pointer Helpers`を使います。
- 試験用補助オブジェクトはレンダー非表示です。Outlinerに`SP · ...`として現れるのは正常です。

## UDP入力をPCだけで確認

開発キットを解凍し、Blender側で`UDP / future phone input → Start UDP Receiver`を押します。
初期設定は`127.0.0.1:5005`で、同じPCからの入力だけを受け取ります。LANを有効にする必要はありません。

別途Python 3.11以降が入ったPCで、開発キットのフォルダから次を実行します。

```console
python tools/udp_sender.py --duration 30
```

Windowsで`python`が見つからず`py`が使える場合は、先頭を`py -3`に置き換えます。
通信の動作とクラッチを一緒に確認する場合：

```console
python tools/udp_sender.py --duration 30 --clutch-demo
```

選択中の物体の掴みも自動で試す場合は、**必ず練習シーンで**実行します。

```console
python tools/udp_sender.py --duration 20 --grab-demo
```

送信プログラムはデモ座標を生成するだけで、スマホの位置を測ってはいません。送信成功表示だけではBlenderとの接続成功を意味しません。BlenderパネルのAccepted件数とポインタの動きを確認してください。

### 将来スマホからつなぐ場合

同じ信頼できるLANに置き、`Allow LAN devices`をONにして受信します。トークンが空なら開始時に生成されます。
LANモードではBlenderの`Allow Online Access`もONにする設計です。ただし、このアドオンから外部サーバーへ情報を送る処理はありません。
Windowsファイアウォールで受信を許可する場合はプライベートネットワークに限定し、ルーターのポート開放はしないでください。

スマホ側はPCのLAN内IPv4アドレス・UDPポート・トークンを指定して、同梱の`PROTOCOL.md`どおりのデータを送ります。トークンは平文です。暗号化やインターネット越しの安全な接続を提供するものではありません。

## 困ったとき

**Spatialタブがない**：アドオンが有効か、マウスが3Dビューポート内にあるかを確認します。BlenderのPython Consoleエディターではなく3D ViewportのNパネルです。

**キーで動かない**：Object ModeでStart Keyboard Testを押し、Follow inputがONか確認します。日本語IMEを英数入力に切り替えて試してください。画面にPC TESTと出ている状態がキー操作モードです。

**掴めない**：通常のマウスで対象を選択し直してください。この版は近接選択ではありません。拘束・変形ロック・リンクデータの制限も確認します。

**初めてのUDPデータで移動しない**：最初の有効パケットは基準位置になります。2個目以降で異なる座標を送ると、その差分から移動します。

**ポートを開けない**：別のBlenderウィンドウや同じポートを使うアプリを停止するか、両側のUDPポートを同じ別番号に変更します。

**接続後に固まる**：0.75秒以上有効な入力が来なければ安全のため停止・解放します。再接続時は座標基準を取り直します。掴むボタンは一度離してから押し直してください。
