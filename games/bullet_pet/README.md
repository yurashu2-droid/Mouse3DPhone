# 弾を飼う / Bullet Pet

スマホを弾の器にする、PC＋iPhoneの二画面ゲーム試作です。PCの敵弾を受けとめ、手元で同じ色・同じレベルの弾を合成し、敵へ返します。

## Godot 3D版（推奨）

`Start-Bullet-Pet-3D.cmd` から起動します。PCはGodotの3Dアリーナ、スマホはWebGLの立体容器です。サーバーが起動中ならそのまま接続し、未起動なら一時LAN許可を作って起動します。右側にIPv4と接続コードを表示します。

PCだけの操作は「PCだけで遊ぶ」→マウスで受け口・狙い、矢印/WASDで器を傾け、Spaceで発射。Escは停止。iPhoneアプリ0.4.0のゲームモードから同じサーバーへ接続できます。アプリの再ビルドなしで3D容器を読み込みます。

`BulletPet-PC-3D.zip` はGodotランタイムを含みます。ソースだけをcloneした場合は、Godot4を `runtime/Godot.exe` に置くかPATHへ登録してください。開発に使用した版は4.7.2。Godotプロジェクトは `games/bullet_pet/godot/project.godot` から開けます。Python3.11以上も必要です。

Godotのウィンドウを閉じるとPCの入力を停止しますが、スマホが接続できるサーバーは残ります。終了は接続ページの「サーバー終了」。サーバーは最長2時間で停止します。

## Windowsで起動

リポジトリ直下の `Start-Bullet-Pet.cmd` を実行します。Windowsの確認は「はい」。TCP8767を同じサブネットから一時許可してサーバーを起動します。ゲーム終了時または2時間で一時ルールを削除します。起動エラーは `dist/bullet-pet/launcher.log`。

PC画面：<http://127.0.0.1:8767/>。PCだけで試す場合は「デモに参加」を押し、容器をドラッグまたは矢印/WASDで操作し、Spaceで発射します。PCとスマホで同時に操作権を持つことはできません。切り替えは「停止」してから参加、またはPCの「最初から」。

## iPhoneで操作

1. Spatial Pointer **0.4.0 / build4**を同じサイドロード方法で署名・インストール。
2. メイン画面右上のゲームコントローラーアイコンを押す。Blenderへの送信は止まります。
3. PC画面のIPv4、ポート8767、6桁コードを入力し「ゲームを開く」。BlenderのPairing Tokenとは別です。
4. 楽な縦持ちで「参加 / 再開」を押す。左右の傾きで受け口と狙いを移動、上下左右の傾きで器の中の弾を転がします。「いまの持ち方を中央に」で基準を合わせ直せます。
5. GROW/FIREで「発射」。一番大きい弾を使います。敵の位置へ狙いを合わせてください。

PC画面の接続リンクをSafariで開いても、指で容器をドラッグして遊べます。HTTP接続のSafariで傾きセンサーが動くとは扱っていません。傾き入力には上記ネイティブアプリのゲームモードを使います。

接続が切れたり画面を離れたりすると1.5秒以内に一時停止。戻ったら参加を押し直します。別端末が操作中のときは自動で操作権を奪いません。

## ルール

- CATCH8秒：受け口に弾を合わせて取り込み。逃した弾は小さな得点減少だけ。
- GROW6秒：攻撃は止まる。同色・同レベルの接触で合体。異色の接触で両方消えてライフ減少。
- FIRE6秒：狙って発射。GROWから発射してもFIREへ移れる。威力はレベル1で8、2で20、3で50と、合体にボーナスが付く。
- 2分以内にボスHP100を削れば成功。ライフ5を失うか時間切れで終了。器は6個まで。

## 技術と検証

Python3.11以上の標準ライブラリのみ。ルートから `python -X utf8 games/bullet_pet/server.py` で直接起動も可能です（その場合、必要なら使用するPythonのTCP8767をLANから許可）。別ポートは `--port 8768`。

```sh
python -X utf8 -m unittest discover -s games/bullet_pet/tests -v
```

進行・衝突・合体はPCの60Hz更新、状態配信は30HzのSSE、各画面はCanvasで補間描画します。動画配信ではなく、iPhone側にカメラやARKitを要求しない傾き操作の試作です。最終的な6DoFゲームSDKではありません。

ゲーム用コードはサーバー起動ごとに変わります。LAN内試作用のHTTPで暗号化されません。コードを持つ同じLANの端末が参加できるため、インターネットへ公開する用途にはしないでください。PCページの「サーバー終了」で停止できます。ブラウザーを閉じるだけでは停止しません。

既存Blender用UDP5005・視点HTTP5006とは別ポートです。既存のBlenderシーンやトークンは変更しません。実際のiPhoneの傾き方向・操作感・画面のサイズは実機で確認してください。
